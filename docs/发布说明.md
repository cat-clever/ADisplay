## 安装

各平台的安装步骤、系统拦截怎么放行、搜不到设备时该查什么，
见仓库里的 [安装说明](https://github.com/cat-clever/ADisplay/blob/main/docs/安装说明.md)。

| 平台 | 文件 | 说明 |
| --- | --- | --- |
| Windows x64 | `adisplay-windows-x64.zip` | 解压后运行 `ADisplay.exe`。首次运行放行 SmartScreen 与**防火墙**（必须勾「专用网络」，否则手机搜不到设备）。 |
| Windows ARM64 | `adisplay-windows-arm64.zip` | 同上。适用于骁龙 X 系列等 ARM 笔记本，原生运行。 |
| macOS（Apple Silicon + Intel） | `adisplay-macos-universal.dmg` | 打开 dmg 拖进「应用程序」。首次启动需在「隐私与安全性」放行，并**允许「本地网络」权限**（否则广播会被系统静默拦掉）。 |
| Android TV / 电视盒子 | `adisplay-android-tv.apk` | U 盘或 `adb install` 侧载。 |

## 当前进度

> 这一段要跟着实际进度更新。发版前记得改 `docs/发布说明.md`。

| 批次 | 内容 | 状态 |
| --- | --- | --- |
| 0 | 工程骨架、C ABI、四平台 CI 与自动发版 | 已完成 |
| 1 | 设备发现：mDNS 广播与 SSDP 应答 | 已完成 |
| 2 | DLNA 接收：设备描述、SOAP 控制、GENA 事件 | 已完成（协议层） |
| 3 | 媒体管线：解码、硬件解码优先、渲染、音频输出、音画同步 | 未开始 |
| 4 | AirPlay 镜像：配对、FairPlay、镜像流解密、RAOP 音频 | 未开始 |
| 5 | Android TV：JNI 接核心库、遥控器界面、开机自启 | 未开始 |
| 6 | 体验与安全：托盘常驻、白名单、全屏截图、中英双语 | 未开始 |

### 这一版能做什么

- **手机投屏列表里能看到这台电脑**（mDNS 与 SSDP 广播）。
- **Android 视频 App 能发现设备并下发播放与控制指令** —— 手机上会有「已投屏」「已暂停」这类反馈。
- 设备名称可以随时修改，即刻生效，不需要重启软件或重新配对。

### 这一版还不能做什么

- **屏幕上不会有画面。** 媒体管线（解码与渲染）在批次 3，AirPlay 镜像流在批次 4。
  现在 SOAP 的控制指令会被正确处理并应答，但没有播放器去执行它。
- **Android 端只是界面骨架。** 那个 APK 能显示待机页、能响应触屏与遥控器，
  但还没通过 JNI 接上核心库（批次 5），所以它接收不了投屏。
  目前可用的是 Windows 与 macOS 两个桌面端。
