# ADisplay 安装说明

各平台的安装包在 [Releases](https://github.com/cat-clever/ADisplay/releases) 页面下载。

> **当前版本状态**：批次 0–4 已完成 —— iOS 屏幕镜像的画面与声音在 Windows / macOS /
> Android TV 三端均可用，DLNA 也都能用；批次 5（电视端）与 6（体验与安全）部分完成。
> 各批次的完成标志 vs 现状、已知问题、以及决定不做的方向，见
> [进度与已知问题](https://github.com/cat-clever/ADisplay/blob/main/docs/进度与已知问题.md)。
>
> - 手机投屏列表里能看到这台电脑。
> - Android 视频 App 点投屏后，画面与声音都会出来；播放、暂停、拖动、调音量都由手机控制。
> - iPhone 控制中心「屏幕镜像」能看到这台设备，投出画面与伴音。
>
> 如果手机搜不到设备，请先查上面各平台的「系统会拦两次」那两节，
> 那是实践中最常见的原因。

---

## Windows

**下载**：`adisplay-windows-x64.zip`（普通 PC）或 `adisplay-windows-arm64.zip`（骁龙 X 系列等 ARM 笔记本）

**安装**：解压到任意目录，双击 `ADisplay.exe`。绿色版，不需要安装程序，删目录即卸载。

### 系统会拦两次，都要放行

1. **SmartScreen**：首次运行会弹「Windows 已保护你的电脑」。
   点「更多信息」→「仍要运行」。

2. **防火墙**（这一步最关键）：首次运行会弹「是否允许 ADisplay 在专用网络上通信」。
   **必须勾选「专用网络」并允许**。
   拒绝了的话，手机端根本看不到这台电脑 —— 而且程序本身不会有任何报错，只是安静地收不到东西。

   如果不小心点了「取消」，去手动补一条：
   `控制面板 → 系统和安全 → Windows Defender 防火墙 → 允许应用通过防火墙`，
   找到 ADisplay 勾上「专用」。

### 为什么必须放行防火墙

接收端要监听 7000（AirPlay）、49152（DLNA）等端口，还要收发 mDNS（UDP 5353）和
SSDP（UDP 1900）的组播包。这些在 Windows 上默认被入站规则挡住。

## macOS

**下载**：`adisplay-macos-universal.dmg`（同一个包同时支持 Apple Silicon 与 Intel）

**安装**：打开 dmg，把 ADisplay 拖进「应用程序」。

### 系统会拦两次，都要放行

1. **Gatekeeper**：首次启动提示「无法打开，因为 Apple 无法检查其是否包含恶意软件」。
   去 `系统设置 → 隐私与安全性`，在下方找到 ADisplay 的提示，点「仍要打开」。
   （自用项目没有开发者签名与公证，这是预期行为。）

2. **本地网络权限**：首次启动会弹「ADisplay 想要查找并连接到本地网络上的设备」。
   **必须点「允许」**。

   这是 mDNS 能不能工作的前提。macOS 12 起，没有这个权限的话组播广播会被系统
   **静默丢弃** —— 程序日志里看不出任何异常，只是手机上永远看不到设备。

   如果误点了「不允许」：`系统设置 → 隐私与安全性 → 本地网络`，把 ADisplay 打开。

### 7000 端口冲突

macOS 12 及以上自带「AirPlay 接收器」，**默认占用 5000 与 7000 端口**。

ADisplay 启动时会检测到这一点，自动换一个可用端口并在日志里记一条警告。
但更彻底的做法是关掉系统的：

`系统设置 → 通用 → 隔空投送与接力 → AirPlay 接收器 → 关闭`

关掉之后 ADisplay 就能用标准的 7000 端口，与 iPhone 的兼容性最好。

## Android TV / 电视盒子

**下载**：`adisplay-android-tv.apk`

包里同时带了 **arm64-v8a** 与 **armeabi-v7a** 两个 ABI，64 位的新盒子与 32 位的老板子
都能装。装完可以在电视上跑 `getprop ro.product.cpu.abi` 对一下实际用的是哪一份。

**安装**（二选一）：

```bash
# 方式一：adb
adb connect <电视IP>:5555
adb install -r adisplay-android-tv.apk

# 方式二：U 盘
# 把 apk 拷到 U 盘 → 插到电视 → 用文件管理器打开安装
```

需要先在电视上开启「允许安装未知来源的应用」（各品牌路径不同，通常在
`设置 → 安全` 或 `设置 → 关于 → 连点版本号进入开发者模式`）。

### 一个已知的电视端坑

- **后台被清理 / 开机不自启**：ADisplay 自己声明了开机自启（`BOOT_COMPLETED`）——
  上次把接收服务开着的话，重启后会自己接着跑。但**部分国产定制系统默认拦第三方应用
  自启**，声明了也不生效，表现是「重启之后手机又搜不到电视了」。两条都要做：

  1. `设置 → 应用 → ADisplay → 省电策略` 改成「**无限制**」（不然后台会被杀掉）；
  2. 在系统的「**自启动管理 / 允许自启动**」白名单里勾上 ADisplay（各品牌叫法不同，
     常见于「手机管家」类应用或 `设置 → 应用 → 权限` 里）。

### 手机搜不到电视时：打开电视的热点

有两个常见原因会让手机找不到这台电视：路由器开了 **AP 隔离**（同一 Wi-Fi 下设备互相
不可见），或者手边根本没有可用的路由器。这两种情况都可以绕过去 —— **让电视开热点，手机
连上它**，两者就在同一张网里了：

1. 待机页最下面有【**打开热点设置**】，按它跳到电视系统的热点页；
2. 在那一页把热点打开（有些电视把它放在「网络与互联网」里，找不到就用系统设置自己翻）；
3. 手机上连上这个热点，然后照常投屏。

**只能跳过去、由你按一下** —— 真热点（带上网共享那种）是系统签名级权限，任何第三方应用
都开不了，所以程序替不了你这一步。另外这条**只适合投屏（镜像）**：热点不给客户端上网，
所以 B 站那类「电视自己去互联网拉流」的投屏，电视还得同时连着网线或原来的 Wi-Fi。

### 镜像画质：默认「流畅」，4K 电视可以调高

待机页上有一行「镜像画质」，三档：

| 档位 | 手机编码的分辨率 | |
| --- | --- | --- |
| 流畅 | 1920×1080 | **电视端默认** |
| 均衡 | 2560×1440 | 桌面端默认 |
| 高清 | 3840×2160 | 4K 电视/大屏想看清就选它 |

电视端默认给「流畅」，是因为很多人在用 1–2 GB 内存的老盒子，解码 1440p 以上会吃力。
4K 电视上想全屏看清，改成「高清」。桌面两端（Windows / macOS）的默认仍是「均衡」——
那边是 Retina 屏，降到 1080p 反而发虚。

**已经改过这一档的机器不受影响**：存下来的选择永远优先，新默认只对没选过的机器生效。

它改的是**手机按多大分辨率编码屏幕**，所以**只在手机下次连接时生效** ——
投屏中改这一档，当前这一路不会变。这是核心的设计（尺寸是在应答 `/info` 时
给出去的），不是坏了。

## 通用要求

### 手机和电脑必须在同一个局域网

- 推荐 **5GHz Wi-Fi** 或**网线**。2.4GHz 在拥挤环境下延迟和丢包都明显更差。
- 访问设备的电脑上如果装了 VMware / VirtualBox / WSL / VPN，它们会创建虚拟网卡。
  ADisplay 默认忽略这些网卡，只在实际的局域网上广播 —— 所以不会把广播发错网段。

### 电视/手机端的日志文件

Android 端的日志除了显示在抽屉里，**每一行也会写进一个文件**：

```
Android/data/com.adisplay.tv/files/adisplay-log.txt
```

（应用自己的目录，不需要任何权限。`adb pull` 或者电视上的文件管理器都能取到。
文件上限 2 MB，超了会从头开始记并留一行说明。）

抽屉里的三个操作：**复制全部**（拷到剪贴板）、**导出日志**（走系统的保存对话框，
位置你自己挑，内容是不受 500 行限制的完整那份）、**清除日志**（窗口与文件一起清）。

### 界面语言

三端都能中英双语：**电视端**在待机页最下面那行「界面语言」，**Windows / macOS** 在设置区
里同样一项。切换**立刻生效，不用重启应用**；没选过时跟随系统语言，非英文一律按中文。
日志不跟着切（一律中文），核心给出的少数提示（例如设备名不合规的具体原因）也还是中文。

### 路由器设置

有些路由器默认开启 **AP 隔离**（客户端隔离），同一 Wi-Fi 下的设备互相不可见。
表现就是手机完全搜不到电脑。需要在路由器管理界面关掉这个选项。

## 常见问题

| 现象 | 多半是什么 |
| --- | --- |
| 手机投屏列表里没有这台电脑 | 防火墙没放行（Windows）/ 本地网络权限没给（macOS）/ 路由器开了 AP 隔离。**先查这三个。** |
| 刚才还能用，换了网络就搜不到了 | 电脑 IP 变了。程序会监听网络变化并重新注册广播，稍等几秒；若仍不行请重启接收服务。 |
| macOS 上提示端口被占用 | 系统自带的 AirPlay 接收器占了 7000。关掉它，或忽略这条自动换端口的警告。 |
| 画面卡顿、花屏 | 2.4GHz 拥塞或丢包。改用 5GHz 或网线。 |
| 电视端应用莫名退出 | 被系统清理了后台。加进省电白名单。 |

## 卸载

- **Windows**：删掉解压出来的目录。可选：清掉 `%APPDATA%\ADisplay`（配置与日志）。
- **macOS**：从「应用程序」拖到废纸篓。可选：清掉 `~/Library/Application Support/ADisplay`。
- **Android TV**：`adb uninstall com.adisplay.tv` 或在电视上卸载。
